We recently completed a replacement reanalysis for SODA 2.0.3.
The new reanalysis is called SODA 2.0.4, and address two issues.

    One issue has to do with the erroneous Argo data that came from
WHOI.  This data has been reprocessed.  The reprocessed data is
in the Atlantic Ocean, and so particularly for the Atlantic Ocean the
new run should be used.

    The second difference is that SODA 2.0.4 goes until December 2007,
whereas SODA 2.0.3 only runs up to November 2005.

    You should be able to download SODA 2.0.4 from:

                  http://soda.tamu.edu/

All the best,
Ben
